¿Cómo funciona?

Es un análisis estático: lee el texto del script y busca patrones conocidos. Nunca lo ejecuta.

  1. Pegas el código

    Se trata siempre como texto no confiable, jamás como un programa.

  2. Se ignoran los comentarios

    Así un aviso dentro de un comentario no genera alertas falsas. Los números de línea se conservan.

  3. Se aplican las reglas

    Carga remota, peticiones de red, credenciales, ofuscación, acceso a archivos y más.

  4. Recibes el informe

    Nivel de riesgo, fragmentos, explicación sencilla y recomendaciones.

Advertencias y limitaciones

  • Hay falsos positivos. Muchos scripts legítimos usan loadstring, peticiones HTTP u ofuscación para proteger su trabajo.
  • Hay riesgos que no se detectan. Un script bien escondido puede pasar desapercibido. Un nivel «Bajo» no es garantía de seguridad.
  • No verifica el comportamiento real. Como no ejecuta el código, no puede confirmar qué hace, ni ver lo que descargaría de internet.
  • Nunca te pediremos credenciales. Ni contraseña, ni cookie .ROBLOSECURITY, ni inicio de sesión. Si alguien lo pide en nombre de ScriptGuard, es una estafa.
